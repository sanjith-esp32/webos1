# LumenOS

LumenOS is a public, password-free personal web operating system built for the Hack Club webOS batch. It is a dependency-free static site made with HTML, CSS, and JavaScript.

## Run it

Open `index.html` directly in a browser, or serve the folder with:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Included

- Four draggable windows: Welcome, Field Notes, Pulseboard, and About
- Generated multi-entry Field Notes app
- Live clock and focus ordering
- Responsive layout
- Extra feature beyond the guide: Focus mode, with `F` shortcut and timer
- No authentication or password gate

Progress notes are in `devlogs/`.
